# UI 精准布局契约

UI 布局通过参照关系表达，不以无语义的孤立屏幕坐标逐屏手调。每个组件记录父级坐标系、参照物、双方停靠点、水平/垂直距离、尺寸策略、布局组、顺序、安全区、方向/断点、动态内容和项目量化误差阈值。

资源原点/纹理锚点、布局停靠点和动画偏移分别记录。`x/y` 只能表达相对已声明参照物的本地距离。

## V 阶段

- V1：冻结信息层级、布局契约、第一视觉目标和必要灰盒；改变参照物、坐标系、布局组、安全区或响应式策略时返回 V1。
- V2：关键画面沿用契约，并在动态可玩样片验证文本变化、成员显隐、输入反馈和小屏缩放。非作者 F2 用参照线和边界检查关系。
- V3：选择矢量/字体/九宫格/位图等资产路线，分别记录资源锚点与布局属性；不得默认从整屏效果图裁 UI。
- V4：验证资源边界、九宫格、字体授权、缩放和纹理预算，不重新发明布局规则。
- V5：通过统一入口实现；在基准、最窄、最宽视口、安全区、方向、动态文本和成员变化时测量边界、中心、间距与累计漂移。跨状态和响应式风险在 F3 关闭。

只修改已冻结契约中的单个距离或间距，且不新增资源、不改变结构或响应式行为时可走快速通道。截图比较必须记录 ROI、容差、稳定帧和遮罩；像素差不能替代布局语义与动态可用性。
