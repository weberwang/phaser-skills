# 多级漏斗审核

标准、发布通道的每个候选增量、视觉阶段产物、模块方案和发布候选都执行本漏斗。G0 至 G3 仍表示项目阶段；F0 至 F4 表示单个候选物的审核深度，两者不得混用。快速通道至少执行 F0、F1，风险或影响扩大时立即升级通道并继续后续层级。

## 漏斗原则

- 同一候选物严格按 F0 → F1 → F2 → F3 推进，存在受保护决策时再进入 F4；不同候选物可以并行。
- 上游消除完整性、确定性和专业问题，下游只审新增风险、跨域冲突与必须人工取舍的事项，不重复全量审核。
- 每轮一次性返回当前层已发现的问题清单，按 P0 至 P3 排序；修订后只复核变更影响面和必要回归集，禁止逐条挤出问题。
- P0/P1 直接退回责任层，P2 在当前层修复后复核，P3 记录但默认不阻断；累计 P3 形成系统性风险时升级为 P2。
- 证据不足使用“未验证”，不能用角色声明、沉默、后续产物或其他版本的结论补齐。
- F4 只接收无法由事实和证据消除的受保护决策。技术缺陷、缺证、未完成项和有明确规则的选择不得转嫁给人工。

## 审核层级

| 层级 | 负责人 | 筛选内容 | 退出条件 |
| --- | --- | --- | --- |
| F0 入口筛选 | 总控 | 候选物身份、版本、范围、通道、所属 G 门、负责人、验收标准、影响面、依赖、证据索引和重复项；判断是否需要更重通道。 | 输入完整且审核范围明确；缺项、错通道或重复候选直接退回，不进入专业审核。 |
| F1 证据筛选 | 交付负责人 | 运行适用的静态检查、测试、构建、资源/授权检查、截图或录屏采集；对照清单自检，并提交实际结果与已知缺口。 | 所有硬性检查可复现，P0/P1 清零；失败项在责任域内修复，不向下游传递。 |
| F2 专业筛选 | 对应专业角色；不能由产物作者代替独立审阅结论 | 核对专业契约、边界、质量、性能、可维护性、资源和平台规则；验证 F1 证据是否足以支持结论。 | 专业问题关闭，或明确列为需要跨域处理的冲突；输出一次性问题清单和差异化复核范围。 |
| F3 综合筛选 | 总控组织受影响角色，候选构建由测试角色给出独立结论 | 核对跨模块集成、功能与视觉双验收、回归、渠道影响、风险聚合、证据一致性和质量门条件；把可由现有规则裁决的问题在此关闭。 | 无未处置 P0/P1，P2 已关闭；只剩受保护决策时形成最小人工决策包，否则直接通过当前 G 门审核。 |
| F4 人工决策 | 人工 | 只决定产品范围与体验方向、不可逆或高成本模块边界、视觉方向、预算/授权/合规、风险豁免、目标指标与发布放行。 | 明确记录“通过、修改后重提、拒绝”及适用候选版本；未答复不得推断通过。 |

F2 缺少第二个实际专业角色时，由总控依据该专业检查表执行，但必须标记“总控代审”，不能伪造独立审阅。F3 不得复用 F1 的作者自检作为独立测试结论。

## 审核包

每个候选物使用一个稳定审核 ID，提交包至少包含：

| 字段 | 要求 |
| --- | --- |
| 候选物 | 类型、稳定 ID、路径或构建、当前版本、所属 G 门与 A 阶段 |
| 变更 | 本轮差异、影响范围、明确排除项、被作废的旧证据 |
| 标准 | 可观察验收条件、适用检查表、目标设备或视口 |
| 证据 | 可复现命令、环境、日志、截图/录屏、对比产物与结果 |
| 问题 | P0 至 P3、归属层级、负责人、处理状态和回归范围 |
| 决策 | 仅在需要 F4 时填写事实、可选项、影响、推荐项和最迟决定点 |

总控在 `docs/control-plane.md` 只保留当前层级、结论、阻断项和证据链接；专业细节写回对应交付物。相同根因合并为一项，不按角色重复登记。

## 受保护决策与批量确认

以下事项必须进入 F4：G0 的核心循环、最小范围、首发渠道与视觉方向；新模块或高影响边界变化；无法从既有基线确定的体验或视觉方向；预算、授权、隐私与合规取舍；质量指标、风险豁免和 G3 发布放行。

相关、低风险且推荐项一致的受保护决策可合并为一个包一次确认。相互依赖、选项冲突或单项失败会改变其他结论时必须拆开。人工只审核差异、风险与可视化证据，不要求重读 F0 至 F3 的全部过程。

A1 至 A6 是生产阶段，不再默认等同于六次人工审批：

- A1 的规则、状态和布局可由明确的已批准契约在 F3 关闭；出现参考无法证明的行为、信息结构取舍或范围变化时才进入 F4。
- A2 涉及新的视觉方向或代表性基准画面时进入 F4；已冻结方向内的派生状态由 F2/F3 审核。
- A3 固定在 F2 专业筛选完成。
- A4 的完整性、拆分和技术规格由 F2/F3 审核；只有新增预算、授权风险、主要识别对象处置或不可逆批量生产成本时进入 F4。
- A5 的文件质量、登记和 Phaser 验证由 F1/F2 完成；偏离已批准视觉方向、存在授权/成本取舍时进入 F4。
- A6 的功能、视觉、回归和清理由 F3 综合筛选；验收标准以外的主观取舍或任务明确要求人工终验时进入 F4。

不得把 A2 的方向批准扩张为 A4/A5 的技术通过，也不得把 F1/F2 的客观通过扩张为 F4 的风险接受。

## 退回与失效

- 完整性或身份问题退回 F0；测试、构建、文件或证据失败退回 F1；单专业问题退回 F2；跨域回归或集成冲突退回 F3；受保护决策变化退回 F4。
- 修订使上游事实失效时，从最早受影响层重跑；未受影响层保留结论和证据，不做全流程重审。
- 候选版本、模块契约、视觉方向、框选清单、资源来源、目标渠道或验收标准变化时，显式标记被作废的证据。
- 人工提出问题时先按根因归入 F1、F2 或 F3；只有问题本身需要取舍时才留在 F4。返工后仍按漏斗重新筛选，不得直接回到人工。
