# F0-F4 统一门

本文件只提供领域编排视图。唯一权威是全局控制面的 [控制模型](../../phaser4-game-workflow-control/references/control-model.md)、[状态门](../../phaser4-game-workflow-control/references/state-gates.md) 和结构化 Schema。

| 门 | 语义 | 编排交付 |
| --- | --- | --- |
| F0 | 授权与流程合规 | preflight 结果、任务授权或必要显式批准、A 等级、路径/目标、基线与停止门 |
| F1 | 规格一致性 | 实际 diff 到 approvedRequirements、模块、领域与阶段的追踪 |
| F2 | 领域质量 | 独立产品/架构/玩法/视觉/资源/音频/数值/QA 结论 |
| F3 | 工程验证 | 当前代码/diff 指纹、实际命令、环境、数据源、文件、判定与未覆盖项 |
| F4 | 高影响集成/发布决策 | A4 精确集成批准；独立发布 Work Item 的 A6 精确发布批准；普通 A3 不适用 |

顺序不可调换或补签。低风险、测试通过、领域通过和模糊用户措辞不能跳门。审批只覆盖当前明确下一门；修改后重新执行受影响的 F0-F4。

## 领域返回结构

- Work Item、阶段、模块、领域、候选和基线身份。
- 覆盖事实、证据、阻断项、未覆盖项和领域结论。
- 实际 diff、路径所有者、A 等级与任务授权/显式批准 ID。
- 证据失效条件和建议返回的最早状态。

领域审查者只能提议和审查。全局控制面独占状态迁移、Approval Ledger 和最终门结论。
