# 依赖能力档与服务边界

本文件是 Phaser 项目按需依赖能力档和 API/服务边界的唯一权威定义。先复用浏览器、Phaser、TypeScript、Vite、现有依赖和项目原语，再按技术设计启用最小能力；初始化不得安装未被实际需求触发的依赖。

## 能力档

| 能力档 | 典型能力 | 启用边界 |
| --- | --- | --- |
| 核心档 | Phaser、TypeScript、Vite 及必要测试工具 | 仅项目基础运行、构建和测试所需 |
| 移动平台档 | Capacitor 与实际使用的原生插件 | 已批准 iOS/Android 容器或具体设备能力；每个插件单独验证 |
| 数据/API 档 | 网络客户端、账号、远程配置、云存档和序列化 | 已有明确 API/数据契约，平台原语和现有依赖不足 |
| 复杂玩法档 | 寻路、额外物理、ECS、脚本或行为系统 | 核心玩法复杂度证明自研轻量方案不足 |
| 高级视觉档 | Shader、Spine、后处理、Tilemap 或资产生产工具 | 冻结视觉方向和预算确实需要，并有目标平台证据 |
| 商业能力档 | 支付、广告、分析、崩溃报告 | 用户明确批准商业/数据能力、合规范围和发布渠道 |

每个新增依赖在 TDD 记录能力档、启用原因、拒绝的 SDK/现有依赖/轻量方案、维护成本、运行时性能和平台风险、验证命令及所有者。一个项目可组合多个档位；能力未采用时不创建 `N/A` 条目。

## SDK 初始化归属

所有实际采用 SDK 的初始化统一放在 `src/bootstrap/initialize-sdks.ts`，由应用装配入口调用；先后依赖、独立并行、延迟触发、核心启动是否等待和失败/重试所有权按[SDK 统一初始化](../../phaser4-game-architecture/references/sdk-initialization.md)在 TDD 逐项记录。各 SDK 的原生 API 与事件仍由平台适配器封装，不在 Scene 或服务构造函数独立启动；插件已管理的传递 SDK 不重复初始化。广告、隐私等独立分支不会因为共用一个编排文件而变成串行依赖。

## API 与服务边界

适用时记录：契约 ID/版本、服务端所有者、认证授权、幂等键与重试/超时策略、客户端兼容范围、数据或存档迁移、回滚、服务端/客户端测试边界、部署监控、备份恢复和外部故障降级。生产或发布变化按审核漏斗触发技术与 Release 通道。

如果任务不负责服务端实现，只记录外部依赖、所有者、契约与客户端边界，不扩张到服务端开发、部署或运维。密钥、令牌和个人数据不得进入仓库。
