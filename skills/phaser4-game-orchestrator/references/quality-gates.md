# 质量门

仅在准备进入或复核对应质量门时读取本文件；以可复现证据判断，不以角色声明判断。

| 质量门 | 必须确认 | 阻断项 |
| --- | --- | --- |
| G0 | 核心循环、最小范围、首发渠道和全局视觉方向获人工结论；视觉基线已记录风格关键词、禁用方向、参考来源/权属、代表性基准画面及完成定义。 | 核心体验、首发渠道或视觉方向不明；参考来源权属无路径；已启用商业能力无实现路径。 |
| G1 | 候选模块在生产实现前完成强制拷问并获批准，TDD 契约与实现一致；本地服务已查重并复用匹配实例或只启动一个新实例；垂直切片具备 A1 至 A6 证据，正式结构与确认稿一致且低保真已删除；参考还原任务已建立逐状态功能契约，功能复现和视觉对比均通过；所有场景通过统一背景适配器，竖屏按高度、横屏按宽度缩放且无黑边；核心循环、测试和生产构建可复现；至少一个目标渠道可运行。 | 未拷问便实现模块；模块边界与实现不一致；未查重便启动或遗留重复服务；参考行为由静态截图猜测、只还原视觉或只验证功能；跳过或倒置美术门；未框全单图便生成；以效果图扁平替代结构化场景；正式资源未登记或验证；低保真仍被引用；背景未确认、出现黑边/透明缝/闪烁或截获输入；不能构建或目标渠道不可运行。 |
| G2 | 范围、模块边界和视觉系统冻结；全部批准功能有代码、契约测试与验收证据；参考还原任务批准范围内的功能契约和逐状态视觉矩阵全部通过；服务身份和复用结论完整且无重复实例；所有正式预制体或场景结构化、可编辑、可测试并持续通过无黑边验证；正式资源有唯一记录、视觉对比、游戏内证据和预算结论；低保真、占位、效果图替代物与未验收资源已清零；P0/P1 已处理或获豁免。 | 任一增量缺少模块批准或 A1 至 A6 证据；参考功能或视觉存在未批准差异；存在未批准依赖、重复服务、扁平场景、重复或未登记资源；实现/结构/视觉/资源变化后未复验；残留低保真、黑色填充或占位；阻断缺陷未处置；候选包不可复现。 |
| G3 | 每渠道候选包和提审资料完整；风险、回滚方案和人工放行齐备。 | 无人工放行、隐私或授权未确认、凭据管理不安全。 |

快速通道不要求进入 G0 至 G3。需求修改影响已通过质量门时，将该门标为待复核，只重跑受影响的验证项。
