# 质量门

仅在准备进入或复核对应质量门时读取本文件；以可复现证据判断，不以角色声明判断。

| 质量门 | 必须确认 | 阻断项 |
| --- | --- | --- |
| G0 | 标准或发布通道的核心循环、最小范围、首发渠道和全局视觉方向获人工结论；视觉基线已记录风格关键词、禁用方向、参考来源/权属、代表性基准画面及完成定义。 | 核心体验、首发渠道或视觉方向不明；参考来源权属无路径；已启用商业能力无实现路径。 |
| G1 | 垂直切片的候选模块图在任何生产实现前完成强制拷问并获人工批准；TDD 记录模块职责与非目标、公开契约、状态所有权、允许/禁止依赖、失败边界、顺序、测试和确认记录，实际实现与之相符。垂直切片具有测试和可复现生产构建；核心循环可完成。无交互背景先生成并获确认，所有场景通过统一适配器接入；竖屏按高度、横屏按宽度缩放且无黑边。正式图片已登记且在 Phaser 中验证；至少一个目标渠道可运行。 | 未划分模块或未拷问便搭建正式骨架/编写生产实现；功能范围批准被冒充为模块边界批准；职责、契约、状态所有权或依赖方向与批准记录不一致；出现循环依赖或未批准共享状态；背景未确认、场景未接入方向背景、竖屏未按高度或横屏未按宽度缩放、出现黑边/透明缝/闪烁、背景截获输入、资源权属不明或所选渠道不可运行。 |
| G2 | 范围、模块边界和视觉系统冻结；全部批准功能已有代码与验收证据；每个新增或边界变化模块都有实现前拷问记录、批准契约和契约测试，代码中没有未批准模块或依赖；全部可见场景持续通过无黑边验证；正式图片有确认、纹理键、视觉对比、接入证据与预算结论；占位资源已清零或获明确豁免；P0/P1 已处理或获豁免。 | 新模块或边界变化未重新拷问、实现与批准契约不一致、存在未批准依赖或多模块写入同一状态、功能仅有规格而未实现、实现/资源/视觉规则变化后未复验、存在未覆盖场景或宽高比、人工要求修改后未重新确认、仍以未确认资源/黑色填充/未批准占位代替、阻断缺陷未处置、候选包不可复现。 |
| G3 | 每渠道候选包和提审资料完整；风险、回滚方案和人工放行齐备。 | 无人工放行、隐私或授权未确认、凭据管理不安全。 |

快速通道不要求进入 G0 至 G3。需求修改影响已通过质量门时，将该门标为待复核，只重跑受影响的验证项。
