# 质量门

仅在准备进入或复核对应质量门时读取本文件；以可复现证据判断，不以角色声明判断。视觉任务同时执行 `visual-quality-gate.md`，参考输入、继续任务、未提出异议或其他阶段批准不得推断为当前阶段人工确认。

| 质量门 | 必须确认 | 阻断项 |
| --- | --- | --- |
| G0 | 核心循环、最小范围、首发渠道和全局视觉方向获人工结论；视觉基线已记录风格关键词、禁用方向、参考来源/权属、代表性基准画面及完成定义。 | 核心体验、首发渠道或视觉方向不明；参考来源权属无路径；已启用商业能力无实现路径。 |
| G1 | 候选模块在生产实现前完成强制拷问并获批准，TDD 契约与实现一致；本地服务已查重并复用匹配实例或只启动一个新实例；垂直切片具备 A1 至 A6 证据，A2/A4/A5 有指向当前版本的明确人工确认，正式结构与确认稿一致且低保真已删除；A4 带编号框选图与完整清单齐全，A5 正式文件、登记、深浅底检查、Phaser 加载/缩放截图、目标视口证据和未验收清单齐全；参考还原的功能复现和同条件逐状态视觉对比均通过；核心循环、测试和生产构建可复现；至少一个目标渠道可运行。 | 视觉重做或参考还原被放入快速通道；未拷问便实现模块；模块边界与实现不一致；未查重便启动或遗留重复服务；从参考输入、沉默或其他阶段批准推断人工确认；只还原视觉或只验证功能；跳过或倒置美术门；未框全单图便生成；主要视觉对象用未批准 `Phaser.Graphics` 替代正式资源；正式资源未登记或未完成 Phaser 验证；参考与运行视口等条件不一致却判通过；低保真仍被引用；不能构建或目标渠道不可运行。 |
| G2 | 范围、模块边界和视觉系统冻结；全部批准功能有代码、契约测试与验收证据；参考还原任务批准范围内的功能契约和同条件逐状态视觉矩阵全部通过，并保存参考图、运行图及并排/叠加/像素差异图；服务身份和复用结论完整且无重复实例；所有正式预制体或场景结构化、可编辑、可测试；正式资源有唯一记录、游戏内证据和预算结论；低保真、占位、效果图替代物与未验收资源已清零；P0/P1 已处理或获豁免。 | 任一增量缺少模块批准或 A1 至 A6 证据；任一人工确认缺少当前版本明确记录；参考功能或视觉存在未批准差异；存在未批准依赖、重复服务、扁平场景、重复或未登记资源；将源码标记、类型/单元测试、构建、无控制台错误、元素存在或主观截图判断冒充视觉通过；实现/结构/视觉/资源变化后未复验；残留低保真、黑色填充或占位；阻断缺陷未处置；候选包不可复现。 |
| G3 | 每渠道候选包和提审资料完整；风险、回滚方案和人工放行齐备。 | 无人工放行、隐私或授权未确认、凭据管理不安全。 |

快速通道不要求进入 G0 至 G3，但只允许 `visual-quality-gate.md` 列出的局部修复；成套视觉重做、正式资源替换或参考还原不得使用快速通道。需求修改影响已通过质量门时，将该门标为待复核，只重跑受影响的验证项。人工指出明显细节不足时必须撤销视觉完成状态并退回 A2、A4 或 A5，不能继续以局部坐标调整掩盖资源质量问题。
