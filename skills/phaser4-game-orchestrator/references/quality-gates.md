# 质量门

仅在准备进入或复核对应质量门时读取本文件；以可复现证据判断，不以角色声明判断。

| 质量门 | 必须确认 | 阻断项 |
| --- | --- | --- |
| G0 | 标准或发布通道的核心循环、最小范围和首发渠道获人工结论；可选能力默认关闭，仅对启用项、实际资源路径和后续指标决策点作结论。 | 核心体验或首发渠道不明；已启用商业能力无实现路径；实际使用资源的权属无路径。 |
| G1 | 垂直切片具有 A1 低保真确认、A2 高保真效果图确认、A3 审阅、A4 全量单图框选确认、A5 正式单图验收和 A6 结构化装配与清理证据；正式预制体或场景与确认稿一致；低保真实现已删除；核心循环、测试和生产构建可复现；至少一个目标渠道可运行。 | 跳过或倒置确认门、未框全单图便生成、以效果图/整屏截图扁平替代结构化场景、正式资源未登记或未验证、低保真仍被引用、只有文档或效果图而无可运行实现、不能构建或目标渠道不可运行。 |
| G2 | 范围冻结；全部批准功能已有代码与验收证据；所有正式预制体或场景结构化、可编辑、可测试；正式资源有唯一有效记录、游戏内证据和预算结论；低保真、占位、效果图替代物与未验收资源已清零；设备与性能证据齐备；P0/P1 已处理或获豁免。 | 任一增量缺少 A1 至 A6 证据、实现/结构/资源变化后未退回对应门复验、存在扁平场景、重复或未登记资源、残留低保真或占位、阻断缺陷未处置、候选包不可复现。 |
| G3 | 每渠道候选包和提审资料完整；风险、回滚方案和人工放行齐备。 | 无人工放行、隐私或授权未确认、凭据管理不安全。 |

快速通道不要求进入 G0 至 G3。需求修改影响已通过质量门时，将该门标为待复核，只重跑受影响的验证项。
