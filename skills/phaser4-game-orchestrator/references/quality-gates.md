# 质量门

仅在准备进入或复核对应质量门时读取本文件；以可复现证据判断，不以角色声明判断。

| 质量门 | 必须确认 | 阻断项 |
| --- | --- | --- |
| G0 | 标准或发布通道的核心循环、最小范围、首发渠道和全局视觉方向获人工结论；视觉基线已记录风格关键词、禁用方向、参考来源/权属、代表性基准画面及完成定义。 | 核心体验、首发渠道或视觉方向不明；参考来源权属无路径；已启用商业能力无实现路径。 |
| G1 | 垂直切片具有实现提交或变更文件、测试结果和可复现生产构建；核心循环可完成；资源依赖与实际加载一致。截图/代码重构已归档输入与权属、运行目标场景、建立对象清单、通过样张审查；每个正式生成/重绘产物有明确人工确认记录，并提供同视口的重构前/目标/重构后对比；正式图片已登记、逐图检查且在 Phaser 中验证；至少一个目标渠道可运行。 | 只有文档或效果图而无可运行实现、视觉基线未批准、仅凭代码推断画面、没有固定视口对比、未审查便批量生成、生成/重绘后未获人工确认便拆分或接入、使用未登记/未验收资源、视觉不一致、关键状态缺失、权属不明或所选渠道不可运行。 |
| G2 | 范围和视觉系统冻结；全部批准功能已有代码与验收证据；正式运行时图片有唯一有效记录、人工确认记录、可寻址纹理键、固定视口对比、游戏内接入证据与预算结论；占位资源已清零或获明确豁免；设备与性能证据齐备；P0/P1 已处理或获豁免；渠道差异有结论。 | 功能仅有规格而未实现、实现/资源/视觉规则变化后未复验、对象清单无处置结论、人工要求修改后未重新确认、存在重复或未登记产物、仍以效果图/未确认资源/未批准占位代替、视觉一致性或阻断缺陷未处置、候选包不可复现。 |
| G3 | 每渠道候选包和提审资料完整；风险、回滚方案和人工放行齐备。 | 无人工放行、隐私或授权未确认、凭据管理不安全。 |

快速通道不要求进入 G0 至 G3。需求修改影响已通过质量门时，将该门标为待复核，只重跑受影响的验证项。
