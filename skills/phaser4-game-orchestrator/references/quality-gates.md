# 质量门

仅在准备进入或复核对应质量门时读取本文件，并先执行 `review-funnel.md`。以可复现证据判断，不以角色声明判断；F4 人工结论只覆盖明确记录的候选版本和受保护决策，参考输入、沉默或其他阶段批准不得推断为通过。视觉任务同时执行 `visual-quality-gate.md`。

| 质量门 | 必须确认 | 阻断项 |
| --- | --- | --- |
| G0 | F0 至 F3 已关闭事实与可行性问题；核心循环、最小范围、首发渠道和全局视觉方向获 F4 人工结论；视觉基线已记录风格关键词、禁用方向、参考来源/权属、代表性基准画面及完成定义。 | 核心体验、首发渠道或视觉方向不明；参考来源权属无路径；已启用商业能力无实现路径；把缺证或技术问题转交 F4。 |
| G1 | 候选模块在生产实现前完成 F0 至 F4 与强制拷问，TDD 契约与实现一致；服务已查重；垂直切片具备 A1 至 A6 的 F1/F2/F3 证据，按规则触发的 F4 均有当前版本明确结论；A4 清单、A5 文件与 Phaser 验证齐全；功能复现和同条件逐状态视觉对比通过；低保真已删除；核心循环、测试和生产构建可复现；至少一个目标渠道可运行。 | 错用快速通道；未完成漏斗或拷问便实现；将作者自检冒充独立审核；从参考输入、沉默或其他版本推断 F4 通过；只还原视觉或功能；跳过或倒置 A 阶段；正式资源缺失、未登记或未验证；对比条件不一致却判通过；低保真仍被引用；不能构建或目标渠道不可运行。 |
| G2 | 范围、模块边界和视觉系统冻结；全部增量通过 F3，所需 F4 结论有效；功能契约和同条件逐状态视觉矩阵通过；服务无重复实例；正式结构可编辑、可测试；资源记录、游戏内证据和预算结论齐全；低保真、占位、效果图替代物与未验收资源清零；P0/P1 已关闭或有 F4 豁免。 | 增量缺少漏斗审核包、模块批准或 A1 至 A6 证据；受保护决策无当前版本记录；存在未批准差异、依赖、重复服务、扁平场景或未登记资源；变化后未从最早受影响层复核；残留低保真或阻断缺陷；候选包不可复现。 |
| G3 | 每渠道候选包和提审资料通过 F1/F2，F3 完成风险聚合；风险、回滚方案和 F4 人工放行齐备。 | 无人工放行、隐私或授权未确认、凭据管理不安全；F3 仍有未处置 P0/P1。 |

快速通道不要求进入 G0 至 G3，但至少执行 F0/F1，且只允许 `visual-quality-gate.md` 列出的局部修复；成套视觉重做、正式资源替换或参考还原不得使用快速通道。需求修改影响已通过质量门时，将该门标为待复核，只重跑最早受影响 F 层之后的必要审核。人工指出明显细节不足时必须撤销视觉完成状态，先归因到 F1/F2/F3，再退回 A2、A4 或 A5；只有取舍本身需要人工时才进入 F4。
