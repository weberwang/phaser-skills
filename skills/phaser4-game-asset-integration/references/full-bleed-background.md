# 装饰性满幅背景

## 适用边界

只适用于不承载交互、文字、关键目标、碰撞、导航或玩法信息的屏幕空间装饰背景。世界空间关卡、Tilemap、可交互物、玩法环境和影响遮挡判断的场景层，使用 `asset-production-routes.md` 的场景/Tilemap或世界/玩法环境路线。

背景不要求早于全部角色或 UI 生产。组件/场景路径在 V1 玩法视觉契约、V2 关键画面和动态可玩样片中与关键对象联合验证；单个原子背景只有在已有适用且有效的契约与预算基线可引用时才跳过 V1/V2，否则升级路径。只有视觉方向、裁切焦点、授权、预算等受保护决策才进入 F4，不普遍请求人工确认。

## 生产与适配

1. 适用 V1 时定义背景与玩家、目标、危险、交互、装饰的层级关系、焦点安全区、对比和遮挡预算；原子背景记录所引用基线及有效性。
2. 适用 V2 时同时放入关键对象和最高干扰状态，验证背景不会抢夺第一视觉目标；原子背景在 V5 动态轨迹中完成同类验证，只看空背景不能通过。
3. V3 记录可编辑源文件/生成记录、基准尺寸、最大纹理、内存、包体、方向变体、裁切和延展规则。
4. 使用统一适配器：竖屏通常按高度覆盖、横屏通常按宽度覆盖；具体规则由项目定义，并保持背景在最低装饰层且不接收输入。
5. V4 验证解码、纹理、采样、四边四角、方向切换和目标宽高比。V5 在真实运动、UI、VFX 和场景过渡中复核可读性与闪烁。

不允许用纯色带、透明缝或复制拉伸掩盖未定义区域；如需生成式扩展，保留生成与编辑记录。完整背景仅可替代装饰层，不得把交互场景扁平化。
