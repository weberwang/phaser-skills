# 视觉与功能还原

参考截图、录屏、运行项目和源码是输入，不是通过结论。参考还原属于 V0 的完整
路径，执行 V1-V5；先建立原创玩法视觉契约，再分析参考如何满足或偏离契约，
避免把临摹顺序置于玩法目标之前。

## V1-V2

1. 玩法建立功能契约：前置状态、输入、规则、状态迁移、时序、反馈、成功/失败
   和异常恢复。静态输入无法证明的行为标为待定义。
2. 记录参考版本、权属、视口、设备像素比、语言、状态、操作轨迹、随机种子和
   动画时间点。
3. 读取并冻结总控的[响应式视觉契约](../../phaser4-game-orchestrator/references/ui-layout-precision.md)：
   四层坐标关系、FIT/RESIZE/COVER、响应式锚点、断点重排、背景覆盖目标、留白/裁切/
   拉伸许可、基准/最窄/最宽/横屏/安全区矩阵，以及动态文本、显隐、滚动、触控和
   resize。任一项未定义标记“响应式契约缺失”，阻断 V2。
4. V2 产出覆盖矩阵的动态可玩样片。必须验证完整 viewport 无非允许留白、背景覆盖、
   safe area、层级、最小可读性、多比例重锚定、间距、显隐、滚动与 resize；仅有
   基准静态图阻断 V3。完整测量字段和脚本见 QA 的[响应式视觉验证](../../phaser4-game-qa-performance/references/responsive-visual-validation.md)。

## V3-V4

按对象稳定 ID 选择资产生产路线和“代码绘制、复用、新生成、重绘、删除”结论。整屏
效果图不得直接作为交互场景；只有 AI 合成栅格路线按需框选拆分。所有正式资源保留
可编辑来源或生成记录、授权和机器清单，并完成资源级验收。V4 的非作者 F2 必须以
完整 viewport 检查资源满幅能力和响应式绑定；算法验证、逻辑画布或 Canvas ROI 不能
替代生产场景证据。

## V5 同条件与动态验收

参考和运行证据使用相同视口、设备像素比、语言、状态、操作轨迹和时间点。截图对比
必须记录 ROI、容差、动态时间采样/稳定帧及遮罩理由，可保存并排、叠加和像素差；生成
式内容、动画和 VFX 不得只靠像素差判断。完整 viewport 截图是过程证据，Canvas ROI
只能补充。

V5 还必须在同一页面重放可复现交互轨迹和动态 resize，验证功能契约、第一视觉目标、
预警、反馈、遮挡、移动端缩小和性能峰值。适用路径由非作者独立 F3 关闭跨域结论；
缺完整 viewport 证据只能标记“未验证”。玩法负责规则、状态和交互；美术负责表现
资源和视觉集成，双方共同关闭 V5 的 F3 跨域问题。
