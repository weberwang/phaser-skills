# 美术生产与结构化装配

新建或重做场景、界面、预制体或成套视觉资源时，严格按 A1 至 A6 顺序执行。人工确认是阶段门禁；未经确认不得用后续产物反向替代前置决策。

## A1 低保真结构确认

1. 玩法使用代码和 Phaser 基础图形生成可运行的灰盒结构，不使用最终美术：矩形、圆形、文本标签、占位颜色和明确边界。
2. 为场景、容器、组件、交互区和资源槽分配稳定 ID，说明尺寸、相对位置、层级、锚点、状态、输入区域、响应式约束、动画意图及复用关系。
3. 将低保真代码、占位资源和纹理键放在独立路径或命名空间，禁止与正式资源共用键，确保最后可完整删除。
4. 在目标画布和至少一种目标输入下运行，提交截图或录屏、结构说明和资源依赖清单，等待人工确认布局、信息层级、操作路径和拆分边界。

未获 A1 确认时只修改低保真结构，不生成高保真效果图。

## A2 高保真效果图确认

1. 以已确认的低保真截图、结构说明、画布比例和视觉方向为约束生成高保真效果图；不得擅自改变已确认的交互结构、内容层级或资源槽。
2. 效果图展示完整状态和关键变体，使用目标分辨率或可证明足够的源分辨率，并记录生成提示、模型或编辑来源、版本及授权信息。
3. 提交低保真与高保真对照，等待人工确认视觉方向、构图、色彩、材质、角色和 UI 风格。

未获 A2 确认时只迭代效果图，不制作正式单图。

## A3 效果图审阅

1. 审阅效果图是否保持 A1 结构，是否覆盖全部状态、反馈、文本安全区和目标宽高比。
2. 检查玩法可读性、视觉层级、遮挡、透视、光照、边缘信息、缩放清晰度、风格一致性、平台安全区和单图可生成性。
3. 把问题标为“通过”“待修改”或“阻断”，附位置、影响和证据；修订效果图后重新执行 A2 确认和 A3 审阅。

只有审阅通过的效果图可以进入 A4。

## A4 单图框选确认

1. 在已审阅效果图副本上用清晰矩形或轮廓框出所有需要生成的独立图片，并赋予唯一编号；不得覆盖或修改原始效果图。
2. 框选必须覆盖角色及状态、部件、道具、地形、背景层、按钮状态、UI 装饰、图标、特效帧和其他运行时资源；纯代码图形、文本和无需拆分的内容明确标为“不生成”。
3. 单图清单逐项关联框选编号、用途、复用关系、目标尺寸、透明要求、锚点、九宫格、动画帧、纹理键、生成/补绘方式及已有资源复用结论。
4. 对遮挡、重叠或效果图中不完整的元素说明补全方式；检查遗漏、重复、错误合并和无运行时用途的碎片。
5. 提交框选效果图与单图清单，等待人工确认。任何框选或清单变化都必须重新确认。

未获 A4 确认时不得生成、拆分或补绘正式单图。

## A5 正式单图生成与验收

1. 按已确认的框选效果图和单图清单执行 references/effect-image-splitting.md，先查重，再生成、拆分或补绘正式单图。
2. 完成透明边缘、深浅底、尺寸、锚点、帧序、九宫格、采样溢色、纹理键、性能和 Phaser 加载验证。
3. 将正式路径、拆分 ID、来源版本、验证证据和发布资格写回资源登记。A4 未列出的新资源必须返回 A4 补充确认。

正式单图未全部通过时，不得开始对应预制体或场景的正式装配。

## A6 结构化装配与低保真清理

1. 玩法使用通过 A5 的资源拼装正式 Phaser 预制体或场景。保持对象独立，以命名容器、图层和 GameObject 表达层级、变换、锚点、深度、交互区、动画、响应式约束和复用关系；除明确批准的完整背景外，不得把效果图或整屏截图扁平化为场景。
2. 对照 A1 结构和 A2 效果图验证布局、状态、操作、缩放、动画、资源释放和目标设备表现；记录偏差。资源问题返回 A5，结构或交互变化返回 A1，并重跑受影响确认门。
3. 正式预制体或场景验收通过后，搜索低保真路径、模块、资源键和引用。只有确认没有运行时、测试、构建或配置引用时，才删除低保真代码和占位资源，并重新运行测试和生产构建。
4. 保留低保真结构说明、各门确认记录、框选效果图、资源登记和正式装配证据，便于审计；只删除低保真实现产物。

完成定义：正式结构可编辑、可复用、可运行、可测试，视觉与已确认效果图一致，全部正式资源可追溯，低保真实现已经删除且删除后构建仍可复现。
