# Phaser 4 美术设计与接入

让视觉资源服务体验，并满足移动端性能和上架权属要求。

快速通道仅读取任务直接相关的资源、代码、规格和验证；标准、发布通道读取 docs/project-profile.yaml、docs/GDD.md、docs/visual-design.md、docs/TDD.md、docs/control-plane.md，美术流从 A1 启动时读取 docs/asset-license-register.md，已有性能计划时再读取 qa-plan。视觉方向、生成式资源、授权、预算或发布资格需取舍时，向总控提交决策包，等待其完成决策门禁。

1. 在 `docs/visual-design.md` 冻结风格关键词、色彩、字体、造型、场景、UI、图标、动画、特效、技术约束、禁用方向和代表性基准画面；视觉基线未获人工批准时，不得批量生成正式资源。
2. 新建或重做场景、界面、预制体或成套视觉资源时，完整读取并严格顺序执行 [references/visual-production-pipeline.md](references/visual-production-pipeline.md)；任何人工确认门未通过时，只返工当前阶段，不得提前生成下游产物。
3. 需要适配不同宽高比、消除黑边或制作场景背景时，完整读取 [references/full-bleed-background.md](references/full-bleed-background.md)。在 A2 高保真阶段优先生成无交互满幅背景，完成人工确认后通过统一适配器应用到每个可见场景。
4. 输入是截图、现有界面、运行场景或源代码且需要重构美术时，完整读取 [references/visual-reconstruction.md](references/visual-reconstruction.md)。将固定视口截图、可见对象清单和保留/重构/新生成/删除结论纳入 A1；将代表性样张纳入 A2，随后继续 A3 至 A6，并保留固定视口前后对比。
5. 进入单图生成阶段后，完整读取 [references/effect-image-splitting.md](references/effect-image-splitting.md)，只以 A4 已确认的框选效果图和单图清单作为输入；效果图不得直接冒充可接入资源。
6. 在资源登记中为每个背景、重构项和单图维护唯一 ID、输入/来源版本、状态、用途、规格与锚点/焦点、交付路径与纹理键、授权或生成记录、发布资格和 Phaser 验证。开工前先查重；已有有效同规格产物时直接复用。
7. 按已确认的低保真结构、背景规则、资源依赖清单和 TDD 接入正式资源，在目标设备验证黑边、输入、尺寸、锚点、焦点、帧序、九宫格、采样和性能问题。
8. 正式结构化预制体或场景验收通过后，确认运行时、测试、构建和配置不再引用低保真代码、资源和纹理键，再删除低保真实现；保留结构说明、确认记录和验证证据。
9. 标准、发布通道在控制面追加视觉基线版本、当前美术门、背景覆盖矩阵、证据或阻断项；快速通道仅在产生未决决策或阻断项时追加。

向架构和玩法提供已批准的视觉基线、背景覆盖规则、低保真结构、框选效果图、单图清单、复用项、规格、锚点/焦点、纹理键和路径约定；向测试提供 A1 至 A6、全场景宽高比、固定视口前后对比、逐图检查、正式装配和低保真清理证据；向发布提供权属清单。任一确认门、背景覆盖、正式资源验证、结构化装配或低保真清理未完成时，不得标为可交付。
